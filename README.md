# @dnd/shared

Общие типы, Zod-схемы и коды ошибок для `dnd-api` и `dnd-frontend`.

Одно описание даёт и типы TypeScript, и проверку в рантайме: сервер
проверяет входящие запросы теми же схемами, по которым фронт
валидирует формы. Контракт между ними физически один.

## Подключение

```json
"@dnd/shared": "github:maksymfediunin/dnd-shared#v0.2.0"
```

`zod` объявлен **пировой** зависимостью, а не обычной. Это
принципиально: при обычной зависимости пакет тянет свою копию, и
`instanceof ZodError` в потребителе перестаёт срабатывать — ошибка
проверки превращается из ответа 400 в ответ 500. Копия должна быть
одна.

Версия привязывается тегом. Обновление контракта — новый тег и
изменение ссылки в обоих потребителях.

## Что внутри

| Путь | Содержимое |
|---|---|
| `enums/` | `Locale` (ru, uk, en), `Role` |
| `errors/` | `ERROR_CODES` — стабильные коды, по ним фронт подбирает перевод |
| `schemas/auth` | регистрация, вход, обновление, сброс пароля |
| `schemas/user` | профиль, правка профиля, смена пароля |
| `schemas/common` | постраничность, формат ошибки |

Сюда не попадают ни Prisma, ни Express, ни React: пакет должен
собираться и на сервере, и в браузере.
